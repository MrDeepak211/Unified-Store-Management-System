# Repository Agent Instructions

For code-writing, code-review, debugging, and refactoring tasks in this repository, follow the project-scoped **Karpathy Guidelines** in `.agents/skills/karpathy-guidelines/SKILL.md`.

Apply them alongside USMS-specific requirements in the existing documentation:
- Think through assumptions and ask only when an ambiguity blocks a safe, correct implementation.
- Prefer the smallest complete solution; do not add speculative features or abstractions.
- Make surgical changes and avoid unrelated refactors or formatting churn.
- Define verifiable acceptance criteria and run the relevant checks; report checks that could not be run.
- Preserve tenant isolation, inventory correctness, payment security, and existing architecture.

For trivial changes, use judgment rather than adding unnecessary process. These guidelines supplement—not replace—project instructions, security requirements, or user requests.
